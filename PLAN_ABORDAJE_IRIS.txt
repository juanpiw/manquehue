================================================================================
                    PLAN DE ABORDAJE: INTEGRACIÓN IRIS
================================================================================

🎯 **PROBLEMA PRINCIPAL:**
Iris no activa filtros porque falta integración entre el sistema de chat (texto y voz) y la arquitectura modular IRISCore.

🎯 **OBJETIVO:**
Crear un bridge que conecte el sistema de chat de Iris (texto escrito y comandos de voz) con la arquitectura modular IRISCore para que los comandos se procesen correctamente usando el sistema ya implementado.

- Si hay conflictos, aislar sistemas
- Si performance es mala, optimizar listeners
