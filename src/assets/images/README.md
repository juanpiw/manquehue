# Imágenes para el Sistema de Navegación

## Estructura de Archivos

Coloca los siguientes archivos de imagen en esta carpeta:

### Imágenes Principales:
- `houseBase.png` - **Mapa de la casa** - Plano del proyecto
- `brand-white2.png` - **Logo** - Logo de la marca en blanco

### Especificaciones Técnicas:
- **Formato**: PNG (para transparencias) o JPG
- **Resolución**: Mínimo 1920x1080 para mapas
- **Tamaño**: Optimizar para web
- **Transparencia**: PNG para logos con fondo transparente

### Configuración:
- **houseBase.png**: Mapa interactivo del proyecto
- **brand-white2.png**: Logo para header transparente

## Notas:
- Las imágenes se cargarán automáticamente cuando estén disponibles
- El sistema maneja la optimización automática
- Los logos se adaptan al tema claro/oscuro
- Los mapas son interactivos y responsivos
