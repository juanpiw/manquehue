# Videos para el Sistema de Navegación

## Estructura de Archivos

Coloca los siguientes archivos de video en esta carpeta:

### Videos Principales:
- `video-0.mp4` - **HOME** - Vista general del proyecto
- `video-4.mp4` - **APARTAMENTS** - Vista de apartamentos
- `video-8.mp4` - **FEATURES** - Características del proyecto
- `video-5.mp4` - **CONTACT** - Información de contacto

### Especificaciones Técnicas:
- **Formato**: MP4
- **Resolución**: Mínimo 1920x1080 (Full HD)
- **Duración**: 10-30 segundos por video
- **Tamaño**: Optimizar para web (máximo 10MB por video)
- **Codec**: H.264 para máxima compatibilidad

### Configuración:
- **Autoplay**: Habilitado para el primer video
- **Loop**: Habilitado para todos los videos
- **Muted**: Habilitado para autoplay
- **Preload**: Metadata para carga rápida

## Notas:
- Los videos se cargarán automáticamente cuando estén disponibles
- El sistema maneja transiciones suaves entre videos
- Los controles de navegación aparecerán automáticamente
- El overlay de contenido se superpone sobre los videos
