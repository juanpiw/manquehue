PLAN DE PRUEBAS REFINADO - INTEGRACIÓN IRIS DASHBOARD MANQUEHUE
================================================================

OBJETIVO GENERAL REFINADO
=========================
Implementar un sistema de control de UI mediante comandos de voz/texto con arquitectura modular y patrones de diseño que permitan:
- REUTILIZACIÓN: Componentes intercambiables para diferentes proyectos
- FLEXIBILIDAD: Fácil modificación de lógica de comandos sin afectar el core
- MANTENIBILIDAD: Separación clara de responsabilidades y puntos de cambio
- ESCALABILIDAD: Adición de nuevos comandos y funcionalidades sin refactorización

ARQUITECTURA PROPUESTA
======================

PATRÓN COMMAND + STRATEGY + OBSERVER

┌─────────────────────────────────────────────────────────────┐
│                    IRIS CORE SYSTEM                        │
├─────────────────────────────────────────────────────────────┤
│  CommandParser    │  CommandExecutor    │  CommandRegistry  │
│  (Strategy)       │  (Strategy)         │  (Registry)       │
├─────────────────────────────────────────────────────────────┤
│                    COMMAND HANDLERS                        │
│  NavigationHandler│  VideoHandler       │  FilterHandler    │
│  (Concrete)       │  (Concrete)         │  (Concrete)       │
├─────────────────────────────────────────────────────────────┤
│                    UI CONTROLLERS                          │
│  ScrollController │  VideoController    │  FilterController │
│  (Adapter)        │  (Adapter)          │  (Adapter)        │
└─────────────────────────────────────────────────────────────┘
